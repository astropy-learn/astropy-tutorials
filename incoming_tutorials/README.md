# How to use this directory

This directory is for use by people submitting new tutorials to Astropy Learn.

To use it:

1. Clone this repository
2. Add your tutorial notebook(s) in this folder
3. Include any data files requirements etc as needed
4. Make a PR to this repository
5. Your tutorial will be reviewed, but once accepted the PR with *not* be merged, instead the new repository specific to your tutorial will be created and it will be moved there

See the [contribution guide](https://learn.astropy.org/contributing/) for more details.
